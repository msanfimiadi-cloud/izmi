# IZMI — запуск на Windows

## Что установить

1. Скачать и установить Unity Hub.
2. В Unity Hub установить актуальную версию Unity 6 LTS.
3. При установке отметить модуль Windows Build Support.
4. Клонировать репозиторий IZMI.
5. В Unity Hub выбрать Add project from disk и указать папку репозитория.

При первом открытии Unity импортирует пакеты и создаст локальные служебные каталоги. Это может занять несколько минут.

## Первый запуск

1. Дождаться окончания импорта и исчезновения индикатора компиляции.
2. В верхнем меню Unity выбрать IZMI → Create Prototype Scene.
3. Открыть созданную сцену Assets/IZMI/Scenes/GlobePrototype.unity.
4. Нажать Play.

Прототип создаётся программно после запуска сцены.

## Управление на компьютере

- левая кнопка мыши и движение — вращать планету;
- колесо мыши — приближать и отдалять;
- кнопка Play — запуск и остановка прототипа.

## Проверка мобильного экрана

1. Открыть Window → General → Device Simulator.
2. Выбрать модель iPhone.
3. Проверить интерфейс в доступных ориентациях и разрешениях.

Device Simulator используется для проверки экрана и базовых взаимодействий, но не заменяет тест производительности на настоящем телефоне.

## Если Unity предложит обновить проект

Разрешить обновление до установленной версии Unity 6 LTS. После успешного открытия необходимо сохранить изменения ProjectSettings и Packages отдельным коммитом.

## Текущий результат прототипа

После запуска должны появиться:

- тёмный космический фон;
- синяя трёхмерная планета;
- освещение;
- несколько маркеров;
- красная точка первой аномалии;
- вращение и масштабирование.

Настоящая текстура Земли, атмосфера, облака, континенты и переход к городу добавляются следующими этапами.
