# IZMI

Глобальная 3D-стратегия о начале зомби-эпидемии и судьбе человечества.

Игрок руководит международным кризисным центром, наблюдает за живой Землёй, исследует инфекцию, распределяет ресурсы и принимает решения, которые постепенно ведут мир к одному из трёх направлений:

1. война с заражёнными;
2. создание лечения;
3. выживание последних людей после падения цивилизации.

Ключевая особенность IZMI — масштабируемая живая планета: от глобального вида Земли до городских улиц с домами, транспортом, людьми, животными и последствиями эпидемии.
